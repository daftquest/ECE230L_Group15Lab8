## Summary
We were given 4 groups of inputs. Each with 4 bits of data. We needed to pass the four bits of data from a certain source to a certain destination. 
This was done by passing the data into a multiplexer to select between the sources.
Then the data was passed to a demultiplexer to choose the destination to which the data is sent. 

## Lab Questions

### In plain English describe the function and use of a multiplexer.
Pass a specific input signal from a collection of many inputs though the block. The specific input is chosen through a unique combination of selector signals. 
The multiplexer does not modify the input signal, it simply passes or not. 

### In plain English describe the function and use of a demultiplexer.
Pass a single input to a specific output from a collection of outputs through the block. The specific output is chosen using a unique combination of selector signals. 
The demultiplexer does not modify the input signal, it simply passes to a specifc output or not.  

### What other uses might these circuits have? (Think Shannon’s)
The multiplexer and demultiplexer can be used to decompose any combination of logic blocks into a many-input multiplexer or many-output demultiplexer.
